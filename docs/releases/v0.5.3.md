## 杏铃同步台 v0.5.3

本版本重点提升同步可靠性与日常操作体验，修复多种可能导致漏同步、重复启动或结果误报的问题，并重新整理了历史同步、自动同步和过滤规则界面。

### 下载

下载与你系统对应的压缩包，解压后运行其中的程序即可，无需安装 Python。

- Windows x64：下载 `tg-channel-sync-v0.5.3-windows-x64.zip`，解压后双击 `.exe`。
- Linux x64：下载 `tg-channel-sync-v0.5.3-linux-x64.zip`，解压后赋予执行权限并运行。要求 glibc 2.35 或更高版本，不支持 Alpine/musl。
- Linux、NAS 和服务器也可以继续使用 Docker Compose 部署。

### 稳定性与正确性

- 修复公开频道积压超过 100 条消息时可能漏同步的问题。
- 修复 JSON 导入在不同来源之间误判重复消息的问题。
- 同步完成后按实际发送、跳过和失败数量展示结果，避免成功状态误报。
- 阻止历史同步重复启动，并完善启动、停止期间的状态保护。
- 增加启动前参数校验，频道或消息范围填写错误时会直接提示。
- 修复账号初始化完成后登录提示仍不消失的问题。
- 连接中断后会明确提示，并在恢复连接时补齐状态与日志。

### 界面与操作

- 自动同步映射支持编辑备注、暂停、恢复，并可一键填入历史同步。
- 历史同步表单更精简，可在当前浏览器恢复或清除上次填写内容。
- 过滤规则支持保存前校验和示例预览，媒体组文字替换行为更加一致。
- 同步模式和相关说明改为更直观的通俗文案。
- JSON 导入与下载重传的媒体哈希开关相互独立，并默认开启。
- “更多选项”改为更明显的折叠面板，增加内容摘要、展开箭头和展开态反馈。
