## 杏铃同步台 v0.5.5

本版本新增中英文界面与快捷语言切换，整理双语项目文档，并改善机器人启动重试与原地重启的稳定性。

### 下载

下载与你系统对应的压缩包，解压后运行其中的程序即可，无需安装 Python。

- Windows x64：下载 `tg-channel-sync-v0.5.5-windows-x64.zip`，解压后双击 `.exe`。
- Linux x64：下载 `tg-channel-sync-v0.5.5-linux-x64.zip`，解压后赋予执行权限并运行。要求 glibc 2.35 或更高版本，不支持 Alpine/musl。
- Linux、NAS 和服务器也可以继续使用 Docker Compose 部署。

### 稳定性与正确性

- Bot 启动遇到临时网络错误、连接超时或代理连接失败时自动重试，每个接口最多尝试 3 次，单次请求超时为 10 秒，两次重试分别等待 2 秒和 4 秒。
- 自建 Bot API 连接失败后回退官方接口并按相同规则重试；Token 无效等明确认证错误直接提示失败。
- 修复关闭与重启时资源清理被提前跳过的问题，完善轮询任务停止、超时取消与后台任务回收。
- 原地重启复用同一事件循环，避免异步客户端跨循环绑定导致重启后异常；关闭期间保护 Bot 模块加载，防止取消或重复加载影响再次启动。

### 界面与操作

- 新增简体中文与 English 界面，默认按浏览器语言列表选择首个支持的语言，没有匹配时使用 English。
- 顶部 GitHub 链接旁新增语言切换入口，首次设置页与主题设置也可切换；选择即时生效并保存在当前浏览器，支持恢复“跟随浏览器”。
- 界面标签、任务状态、确认框和常见操作提示随语言切换，频道名称、规则内容、消息预览和原始运行日志保留原文。
- 新增英文 README，精简项目首页，并将部署配置、功能矩阵、使用限制及源码构建说明整理为独立指南。
