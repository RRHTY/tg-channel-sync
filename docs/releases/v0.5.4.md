## 杏铃同步台 v0.5.4

本版本重新整理了界面布局与主题呈现，并加强媒体组断点续传、发送结果确认和收藏夹账号切换的可靠性。

### 下载

下载与你系统对应的压缩包，解压后运行其中的程序即可，无需安装 Python。

- Windows x64：下载 `tg-channel-sync-v0.5.4-windows-x64.zip`，解压后双击 `.exe`。
- Linux x64：下载 `tg-channel-sync-v0.5.4-linux-x64.zip`，解压后赋予执行权限并运行。要求 glibc 2.35 或更高版本，不支持 Alpine/musl。
- Linux、NAS 和服务器也可以继续使用 Docker Compose 部署。

### 稳定性与正确性

- 修复媒体组跨消息读取批次时可能被拆散、重复同步的问题，保留指定消息范围与媒体遮罩。
- 媒体组按成员逐条检查重复记录，部分消息已同步时只补发缺少的成员。
- 发送前保存发送记录；回包异常、目标消息 ID 不完整或映射保存失败时保留待核对状态，阻止重跑自动重发。
- 映射保存失败时仅重试数据库写入，避免再次发送消息；JSON 媒体组也会检查全部成员的待核对记录。
- 收藏夹的断点、待核对记录和公开频道轮询进度按辅助账号分别保存，同一账号重新登录可继续使用，换号不会删除或误用其他账号的记录。
- 旧收藏夹记录仅向归属可确认且验证成功的账号迁移；无法确认归属的记录保留隔离并提示。
- 完善账号切换、认证、消息编辑和轮询游标保存期间的状态保护，防止使用过期客户端或错写其他账号的进度。
- 修复删除后重新新增收藏夹同步规则时忽略新起点的问题，并隔离损坏会话中的异常账号 ID。

### 界面与操作

- 使用更整齐的卡片布局与更鲜明的主题配色，重新整理历史同步、自动同步、内容过滤和设置区域。
- 支持单页与侧边栏两种布局，设置后保留选择，并适配窄屏操作。
- 历史同步保留“用上次填写内容”和“清除记录”，原“更多选项”的内容直接展示。
- “保存到我的 Telegram 收藏夹”放在接收频道附近，自动同步的“新增同步”按钮更醒目。
- 加强同步规则与过滤规则的分隔、文字层级和字段标签，改善键盘焦点与多主题下的可读性。
- 保存期间防止重复提交和编辑对象错切，失败时保留草稿；切换日志面板保留阅读位置。
