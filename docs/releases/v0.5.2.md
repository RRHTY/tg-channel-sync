## 杏铃同步台 v0.5.2

本版本简化了下载和启动方式。下载与你系统对应的压缩包，解压后运行其中唯一的程序即可，无需安装 Python。

### 下载

- Windows x64：下载 `tg-channel-sync-v0.5.2-windows-x64.zip`，解压后双击 `.exe`。
- Linux x64：下载 `tg-channel-sync-v0.5.2-linux-x64.zip`，解压后赋予执行权限并运行。要求 glibc 2.35 或更高版本，不支持 Alpine/musl。
- Linux、NAS 和服务器也可以继续使用 Docker Compose 部署。

### 更新

- Windows 与 Linux 原生版本改为自包含单文件，不再区分 portable/full。
- 新增 GitHub Actions 双平台自动测试、构建、冒烟验证和发布。
- 首次运行自动创建配置、数据与缓存目录；新配置默认启动后打开 Web 页面。
- 发布包会验证动态业务模块、静态页面、版本与配置写入，并提供 `SHA256SUMS.txt`。
